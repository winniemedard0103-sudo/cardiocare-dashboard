# CardioCare — Cardiovascular Monitoring Prototype

A responsive, clinical-style dashboard for a student portfolio project.

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `cardiocare-dashboard` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and choose **Go Live**.
4. Try the ECG rhythm selector, alert scenarios, trend selector, and patient assessment form.

## Features
- Clinical-style overview with sample vital-sign cards.
- ECG-style waveform simulator with selectable visual patterns.
- Alert simulator with baseline, high-rate, low-oxygen, and signal-unavailable scenarios.
- Fictional patient history table and selectable trend charts.
- Educational patient assessment form with a generated summary.
- Responsive desktop/mobile layout.

## Safety and limitations
- This is a front-end educational prototype only.
- All patient details, measurements, trends, alerts, and ECG-style waveforms are fictional and simulated.
- No physical sensor, wearable, hospital system, or medical API is connected.
- The sample alert scenarios are not clinically validated and are not intended for triage or treatment decisions.
- The assessment form does not diagnose conditions or determine medical urgency.
- The demo does not save data to a server; note/form state exists only in the open page.
- Do not enter real patient-identifiable or confidential medical information.
- If someone has severe chest pain, difficulty breathing, faints, or appears critically unwell, seek emergency medical help.

## Future academic extensions
A future project could use fictional backend data, authentication, audit logs, and a documented API. Actual clinical use would require qualified clinical oversight, validated medical devices, strong privacy/security controls, testing, and applicable regulatory review.
